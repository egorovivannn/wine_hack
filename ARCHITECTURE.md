# Архитектура сканера

## Путь одного запроса

```text
фото → декодирование и EXIF → полный кадр + центральный кроп
     → SigLIP 2 (768 чисел на вид) → сравнение с индексом 2 087 эталонов
     → ранжирование карточек → точный slug → API / карточка / дневник
```

`scanner.catalog` строит детерминированный манифест из `df_2.csv`: дублирующиеся строки одного `slug` схлопываются; расхождения дубликатов отклоняются. Каждый эталон хешируется и индексируется один раз. Если один файл назначен двум карточкам, оба `slug` остаются кандидатами с одинаковой оценкой. Пять карточек без эталона доступны по API карточки, но не участвуют в визуальном поиске.

`scanner.prepare` проверяет исходные архивы по SHA-256 и извлекает из RAR только изображения, указанные в каталоге. `scanner.model_fetch` скачивает закреплённую ревизию SigLIP 2. Манифест, модель, версия предобработки и индекс сверяются при запуске сервиса. Индекс собирается атомарно в `.npz`, рядом хранится метаинформация с хешами.

Для эталона создаются вид полной бутылки и вид этикетки. Для пользовательского фото — вид всего кадра и центральный кроп. Модель выдаёт нормированные векторы; поиск перебирает все 2 087 эталонов и сортирует по `0.35 × cosine(полный кадр, бутылка) + 0.65 × cosine(центральный кроп, этикетка)`. Коэффициенты пока эвристические. Полученный косинус — **визуальная близость, не вероятность и не конкурсный confidence**. Поиск по всем эталонам требует немного памяти, поэтому отдельная ANN-база для такого каталога не нужна.

API запускает один экземпляр модели и индекс при старте. GPU-инференс сериализован блокировкой, чтобы одновременные запросы не переполняли 10 GiB VRAM. Объём загрузки ограничен 16 MiB. Организатору `/v1/eval/predict` выдаёт только `{"slug": "..."}`; продуктовый `/v1/predict` дополнительно возвращает карточку и альтернативы. Мобильная страница хранит заметки только в `localStorage` браузера.

## Что подтверждено

- Все 2 087 эталонов декодируются; перестроенный из RAR набор из 2 087 файлов побайтно совпал с манифестом.
- Текущий индекс создан на RTX 3080 за 169 секунд с batch size 16. Применение к 100 официальным фото заняло около 40 секунд; p50 399 мс, p95 437 мс на фото, без загрузки модели.
- 17 вручную выбранных снимков имеют проверенный `slug`; у 14 Top-1 точен, у 16 правильный ответ в Top-5. Один снимок помечен как отсутствующий в каталоге, один — как неоднозначный из-за нескольких бутылок. Остальные 81 не размечены. Ручной набор выбран по читаемым этикеткам и **не представляет случайную тестовую выборку**.
- Скрипт организатора прошёл сквозной HTTP-тест на трёх изображениях. Эталонные ответы к нему не опубликованы, поэтому факт выполнения скрипта не является оценкой качества.

## Ограничения и экспериментальный план

1. **Похожие этикетки.** Модель может выбрать соседнюю позицию той же серии. Надо отдельно разметить разные сорта и годы, собрать удержанный тест по сеансам съёмки и сравнить OCR, более точный кроп и другой визуальный энкодер. Любое изменение ранжирования принимается только при приросте на удержанном наборе.
2. **Нет бутылки в каталоге.** API обязан вернуть `slug` даже для неизвестной этикетки. Неизвестные примеры не должны создавать ложную оценку точности; для соревнования нужно уточнение, как они размечаются и допускается ли отказ.
3. **Несколько бутылок в кадре.** Сейчас выбирается центральная зона, без детектора. Для полочного кадра с несколькими товарами требуется явный выбор пользователя или надёжный детектор/кроп. Пока нельзя считать произвольно выбранную бутылку правильной.
4. **Общие эталоны.** У 11 файлов по два `slug`; визуальные признаки не различат эти карточки. Нужны дополнительные метаданные или решение организатора об эквивалентности.
5. **Валидация.** У 100 фото нет официальных ответов. Ручные метки хранят доказательство и SHA каждого файла; данные для настройки модели и финальной проверки нужно разделить до подбора весов или порога.

Прежний код в `embedding/` и `detection/` сохранён как исследовательская основа. Его обученные веса не входили в репозиторий, а прежние метрики на WineSensed не переносятся на конкурсные фотографии.
