# Проверка магазинных фотографий

Для всех 13 фото из `data/field/photos` пользователь указал одно правило: цель — центральная бутылка. Первичные снимки визуально проверены без просмотра выдачи модели; каждая строка в `field_center_labels.tsv` содержит SHA-256 фото и видимое основание. Каталог сравнивался по точному товару, а не только по сорту винограда. Снимки и исходный архив остаются в игнорируемом `data/`.

Итог: 7 кадров с распознаваемой центральной бутылкой, точной карточки для которой нет в текущем каталоге (`unknown`), и 6 кадров, где геометрическая середина проходит между двумя **разными** товарами (`ambiguous`). Подтверждённых соответствий `slug` нет. Например, на `IMG_7368.JPG` видна молдавская «Ай-Петри Крым Шардоне Ркацители», а на `IMG_7375.JPG` — грузинская «Алали Пиросмани»; похожие вина в каталоге не являются их точными карточками.

Этот набор полезен для проверки поведения сервиса на реальной полке и винах вне каталога, но по нему нельзя вычислить Top-1 accuracy. API конкурса требует вернуть один `slug` даже тогда, когда точной карточки нет. Поэтому принудительный ответ на этих семи кадрах следует считать ограничением закрытого каталога, а не ошибкой распознавания среди известных классов.

Проверка на ревизии `9f9115f102726e03bb4f038a669abda26c27699c` через `uv run --locked python -m scanner.evaluate --images-dir data/field/photos --labels evaluation/field_center_labels.tsv --output data/evaluation/field_center_hybrid.jsonl --use-ocr` обработала все 13 фото; OCR вызван на 10. SHA-256 таблицы меток — `bc73bc8a7fea5457a244fc81d37236ae1787e8b7615d983b3c67ab28435c9d33`, JSONL с предсказаниями — `ad0f46efe14e13aed3d840956c04d25c2b2acf3dd2f37b1d0155ffd9b3167774`. У каждого кадра сервис вынужденно вернул `slug`; точность осталась `null`, потому что нет подтверждённых соответствий. На семи кадрах `unknown` визуальное сходство выбранного ответа лежало в диапазоне 0,740–0,767, а на 17 подтверждённых официальных фото — 0,741–0,890. Диапазоны перекрываются: один порог сходства не позволит надёжно отсеять неизвестные товары.

Если нужно превратить шесть неоднозначных кадров в однозначные примеры, достаточно указать цель на них по именам файлов: `IMG_7369.JPG`, `IMG_7370.JPG`, `IMG_7371.JPG`, `IMG_7372.JPG`, `IMG_7377.JPG`, `IMG_7378.JPG`. Для измерения точности среди известных вин нужны новые снимки товаров с точным `slug` из каталога; эти 13 кадров такую выборку не образуют.
