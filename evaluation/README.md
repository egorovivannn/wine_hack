# Ручная проверка официальных фотографий

## Полная разметка

[`all_official_labels.tsv`](all_official_labels.tsv) — актуальная ручная разметка **всех 100** снимков организаторов по правилу «центральная бутылка». В каждой строке указаны имя исходного файла, SHA-256 его байтов, статус, `slug` (только при подтверждённом соответствии) и основание решения. Итог: **59 verified, 35 unknown, 6 ambiguous**. Проверка покрытия, хешей, статусов и существования подтверждённых `slug`:

```bash
uv run --locked python evaluation/validate_official_labels.py
```

`verified` означает, что читаемые признаки товара и/или эталонная фотография позволяют выбрать конкретную карточку. `unknown` — видимый товар не найден в текущем `df_2.csv` после поиска по производителю, серии, названию и варианту. `ambiguous` — несколько карточек либо неустранённое расхождение в признаках. Пустой `slug` не является «ошибкой модели». Например, пять кадров ALVEUS Orange Brut остаются `unknown`, хотя в каталоге есть белый и розовый ALVEUS Brut; это другой вариант.

Разметка создавалась после просмотра визуального Top-20 для всех фото, поэтому **не является независимым тестом** модели. Она пригодна для аудита покрытия каталога, поиска ошибок в данных и разработки. Для честной оценки качества потребуются новые снимки или заранее отложенная группа, не использованная при выборе алгоритма и порогов.

`manual_official_labels.tsv` (19 фото) и `holdout_official_labels.tsv` (23 фото) сохранены как **исторические снимки разметки** для воспроизведения опубликованных ранее чисел в [`RESULTS.md`](RESULTS.md). Их строки могут отличаться от актуального файла: повторная проверка, например, нашла точную карточку для «Жемчужная 9 Цитрон, Совиньон Блан», определила полусухой вариант АРАТТИ «Каберне по-белому» и уточнила, что на фото Валерия Захарьина виден «Каберне Совиньон», а не «Бастардо Кефесия». Для новых решений используйте `all_official_labels.tsv`.

## Процедура проверки

Откройте **исходный снимок** и определите центральную бутылку. Прочитайте производителя, серию, сорт/купаж, цвет, сладость и год. Найдите карточки в `df_2.csv` по этим признакам с учётом вариантов написания и сравните эталонные изображения. Не принимайте номер в имени снимка, первую выдачу модели или один лишь похожий дизайн за доказательство.

Для трудных случаев получите Top-20 и лист сравнения:

```bash
uv run --locked python -m scanner.review --image data/official_real_photos/ИМЯ_ФОТО.webp --top-k 20
```

Команда сохраняет результат в `data/evaluation/manual_review/`. Правильная карточка может быть ниже 20-го места; отсутствие в Top-20 само по себе не доказывает `unknown`. При конфликте похожих карточек оставляйте `ambiguous` и указывайте кандидатов в `evidence`. Если фото или каталог обновились, пересмотрите строку и пересчитайте SHA-256.

Собственные магазинные снимки размечены отдельно в [`field_center_labels.tsv`](field_center_labels.tsv); их ограничения описаны в [`FIELD_PHOTOS.md`](FIELD_PHOTOS.md).
