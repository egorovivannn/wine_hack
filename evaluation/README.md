# Ручная проверка официальных фотографий

`manual_official_labels.tsv` — небольшая, намеренно неполная таблица: 17 подтверждённых товаров, один кадр с несколькими возможными целями (`ambiguous`) и один видимый товар, для которого карточка в текущем каталоге не найдена (`unknown`). Каждая строка привязана к SHA-256 исходного изображения и содержит видимое основание идентификации. Отсутствующая строка означает «ещё не проверено», а не ошибку модели.

Для новой метки нужно открыть **исходный снимок**, прочитать название/производителя/сорт/год с этикетки, сопоставить их с карточкой `df_2.csv`, затем записать хеш и доказательство. Нельзя брать за истину имя фото, его числовой префикс, первую выдачу модели или ближайшую похожую карточку. При нескольких бутылках без указания цели ставится `ambiguous`, а когда точной карточки нет — `unknown`; в обоих случаях `slug` пустой.

Эти 17 снимков выбраны вручную для первичной отладки. Доля 14/17 Top-1 и 16/17 Top-5 относится **только к ним**. Для сравнения вариантов распознавания нужно заранее выделить новые удержанные фото по сеансам съёмки и не выбирать коэффициенты по ним. Для вычисления результата с хешами и задержками выполните команду из корневого `README.md`.
