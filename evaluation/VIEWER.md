# Просмотр 100 официальных фото

`scanner.review_app` — доступный только на чтение просмотрщик ручной разметки и визуального Top-20. Он не запускает модель при открытии страницы. Данные берутся из `evaluation/all_official_labels.tsv`, `data/evaluation/manual_review/visual_top20_all.json`, `data/evaluation/manual_review/ocr_all.json`, `data/catalog_manifest.json`, исходных фото и эталонов. Все исходные фото, результаты Top-20 и OCR сверяются по SHA-256 при старте. В `/api/summary` доступны хеши использованных таблиц.

На домашней машине из корня репозитория:

```bash
uv run --locked python evaluation/validate_official_labels.py
uv run --locked uvicorn scanner.review_app:app --host "$(tailscale ip -4)" --port 18766
```

Откройте `http://<Tailscale IPv4 домашней машины>:18766/` с устройства, подключённого к той же сети Tailscale. Сервис слушает только Tailscale IPv4. Порт 18766 можно заменить. Проверка работоспособности: `/health` и `/api/summary`.

Три вкладки разделяют `verified`, `unknown` и `ambiguous`; «Все» объединяет их. Каждое фото показывает основание метки, хеш, OCR, Top-20 кандидатов, карточку выбранного эталона и его изображение рядом с оригиналом. Баллы — взвешенное косинусное сходство до OCR: 35% от всего кадра и 65% от центральной области. Это не калиброванные вероятности. Рядом с исходным баллом показываются отрыв первого кандидата от второго, разброс между первым и двадцатым и отставание каждого кандидата от лидера. Эти разницы удобнее для сравнения внутри снимка, но сами по себе не доказывают правильность карточки. Подтверждённый `slug`, если он есть в Top-20, отмечен отдельно; если отсутствует, показан его эталон вне Top-20. Поиск и выбранное фото отражаются в URL, поэтому ссылкой на конкретный случай можно поделиться внутри сети Tailscale.

Веб-интерфейс нельзя использовать как независимую оценку модели: разметка выполнялась с просмотром Top-20. Старые таблицы `manual_official_labels.tsv` и `holdout_official_labels.tsv` сохранены для воспроизведения исторических метрик; актуальные решения находятся в `all_official_labels.tsv`.
